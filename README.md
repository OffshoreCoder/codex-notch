# Codex Notch

Маленький робот в чёрной области у выреза Mac показывает события локального Codex. Собственная утилита на Swift/AppKit: без зависимостей, API-ключей, скачивания пакетов и установки в Applications. Программа собирается локально из исходников.

## Запуск

1. Откройте `run.command`. Если готовой сборки нет, он соберёт приложение штатным Swift-компилятором (нужны уже установленные Apple Command Line Tools). Запуск выполняется с системным запретом сетевых вызовов. Не требует `sudo` и ничего не добавляет в автозагрузку.
2. Для подключения к Codex откройте `connect.command`. Он добавит свои обработчики в `~/.codex/hooks.json`, сохранив существующие. Перед изменением создаётся точная резервная копия рядом с файлом.
3. В терминале запустите `codex`, откройте `/hooks`, проверьте новые обработчики и доверьте им выполнение. Откройте новый чат в приложении, чтобы настройки точно загрузились. Codex требует этот шаг для пользовательских hooks: программа не меняет записи доверия. Этот интерфейс документирован для Codex CLI; интерфейс настроек hooks в desktop здесь не проверялся.

В обычном состоянии робот встроен в чёрное продолжение выреза справа: ширина 32 пункта, высота равна верхней полосе экрана. Сама фигурка высотой около 24 пунктов находится внутри этой полосы, над рабочими окнами. Физическая область камеры не содержит доступных для рисования пикселей, поэтому программа использует соседнюю область дисплея. На заполненной строке меню это место может пересекаться с ближайшим системным значком; персонажа можно скрыть через его меню и пользоваться штатным значком программы.

Работа, редактирование и проверка действия меняют только выражение робота и цвет значка. Карточка раскрывается под вырезом на 8 секунд при завершении, на 4 секунды при остановке. Наведение на 0,5 секунды или нажатие на робота показывает состояние; нажатие на робота или раскрытую карточку открывает пульт чатов.

На внешнем экране или Mac без выреза обычного плавающего окна нет: остаётся только штатный значок в строке меню. Карточка появляется временно при уведомлении или через пункт «Показать состояние». В меню также можно выбрать экран, скрыть персонажа, посмотреть демонстрацию и завершить программу.

`run.command --demo coding` показывает демонстрацию без изменения настроек Codex. Доступны также `idle`, `working`, `checking`, `finished`, `interrupted`, `unknown`. Для возврата к реальным событиям используйте меню робота.

## Приватность

- Нет серверов, аналитики, телеметрии, обновлятора или сетевого клиента. Используются только системные библиотеки Apple. Графика нарисована программно.
- Обработчик получает JSON события Codex и сразу отбрасывает текст запроса, команды, содержимое файлов, результаты инструментов и путь к переписке.
- На диске остаются только тип события, идентификаторы чата/хода/вызова инструмента, имя инструмента и время. Они нужны для различения нескольких чатов и перехода к нужному чату.
- События находятся в `.codex-notch-runtime` рядом с `.app`. Права папки — `0700`, файлов — `0600`. Приложение удаляет прочитанные события; при выключенном приложении очередь ограничена последними 256 событиями. Настройки Codex сохраняются с правами только владельца.
- Не нужны Accessibility, запись экрана, доступ к контактам, ключам или текстам переписки. Окно не перехватывает фокус клавиатуры.
- `run.command` дополнительно применяет штатный профиль `offline.sb`, запрещающий сетевые системные вызовы. При непосредственном запуске `.app` этот профиль не применяется; сетевого кода в программе всё равно нет. Обработчики hooks запускают отдельный короткий процесс той же программы, который только сохраняет короткое событие без текста переписки и команд.

## Что означают состояния

| Состояние | Источник |
| --- | --- |
| Готов к работе | Открыта локальная сессия, активного хода ещё нет |
| Разбирается в задаче | `UserPromptSubmit` или работа инструмента |
| Пишет код | Выполняется `apply_patch`, `Edit` или `Write` |
| Проверка действия | `PermissionRequest`, без автоматического раскрытия карточки |
| Готово | `Stop` основного хода |
| Остановлен | `Interrupt` |
| Нет свежих событий | 30 минут не поступали сигналы |

«Пишет код» означает наблюдаемое редактирование файлов. Быстрые правки подсвечиваются в течение 1,25 секунды после события, если ход ещё продолжается. Команды Bash не анализируются: изменение файлов через shell может отображаться как обычная работа.

`PermissionRequest` срабатывает **перед** решением об одобрении; другой обработчик, политика или Auto-review могут разрешить действие без участия человека. Этот hook не подтверждает, что диалог разрешения действительно показан. Поэтому робот показывает нейтральное состояние «Проверка действия» и **никогда не раскрывает карточку автоматически** по этому событию. Даже задержка перед показом не решает проблему: уже разрешённая команда может выполняться долго.

У hooks нет отдельного события завершения одобрения, поэтому нейтральная подпись может оставаться до результата инструмента. Для параллельных вызовов одного инструмента она сохраняется, пока все известные вызовы этого типа не завершатся. Автоматическое оповещение о настоящем ожидании ответа человека потребует отдельного проверенного источника состояния; текущая версия не заявляет эту возможность. Она не принимает решений о разрешениях.

Программа наблюдает локальные hooks. Облачные выполнения и инструменты без локальных hook-событий не видны. Если корпоративная политика отключает пользовательские hooks, программа не обходит её. Формат транскриптов не используется.

## Отключение

Завершите программу через её меню и запустите `disconnect.command`. Удалятся только обработчики Codex Notch; все остальные hooks сохранятся. После этого папку программы можно удалить. Никаких LaunchAgents, служб или элементов входа программа не создаёт.

Если перемещаете эту папку, повторите `connect.command`, чтобы обновить абсолютный путь обработчиков, и проверьте доверие в `/hooks`.

## Сборка и проверки

На машине с уже установленными Apple Command Line Tools:

```sh
./build.command
./test.command
```

Сборка рассчитана на macOS 13+ и текущую архитектуру Mac. Бинарники и локальные события не хранятся в Git. Подпись локальная (ad hoc), без отправки программы на сервер нотариализации.

`./CodexNotch.app/Contents/MacOS/CodexNotch --print-hooks` показывает предлагаемый результат слияния настроек без записи. `--hooks-file /path/hooks.json` позволяет проверять подключение на отдельном файле. `CODEX_NOTCH_DATA_DIR` задаёт другую папку событий для тестирования.

Проверки покрывают несколько чатов, параллельные разрешения, поздние события дочерних инструментов, устаревшие сигналы, удаление приватных полей, права/границы очереди и безопасное слияние/удаление hooks. Вызовы hooks всегда возвращают `{}` и код `0`, даже если персонаж недоступен; они не принимают решений о разрешениях.

Официальный контракт интеграции: [Codex Hooks](https://learn.chatgpt.com/docs/hooks).

## Непросмотренные результаты

Каждый завершённый ход попадает в локальную очередь отдельно от состояния других чатов.
На роботе остаётся точка, у значка меню — число результатов. Меню «Ожидают просмотра»
открывает конкретный чат и отмечает выбранный результат просмотренным; можно очистить
всю очередь явно. Открытие Codex другим способом ничего не отмечает автоматически.
Очередь переживает перезапуск. Повторный `Stop` не добавляет уже просмотренный ход.
Хранятся до 512 результатов и 4096 ключей дедупликации; при переполнении удаляются старейшие.
`Stop` означает окончание хода, а не успешность всей задачи.

## Пульт чатов

Нажатие на робота или «Чаты и результаты…» открывает отдельное окно: каждый известный чат,
состояние, время хода и давность сигнала. «Название…» задаёт подпись только на этом Mac.
«Открыть чат» переходит по его UUID и отмечает результаты этого чата просмотренными.
«Просмотрено» позволяет сделать это без перехода. После перезапуска старый работающий чат
показывается как последнее известное состояние до нового события; работа не выдумывается.
Хранятся метаданные до 256 последних чатов и локальные подписи (до 80 символов).

## Уведомлять об одном чате

В пульте у чата нажмите «Уведомлять об этом». Автоматические карточки завершения и остановки
будут появляться только для него. Остальные результаты по-прежнему сохраняются в очереди
и видны в счётчике. Снимите выбор той же кнопкой, чтобы снова получать сигналы всех чатов.
Выбор сохраняется локально между запусками.

## Тихий режим

В пульте «Не отвлекать» включает тишину на 25/30 минут, час или до ручного выключения.
Автоматические карточки не раскрываются, результаты продолжают копиться. После окончания —
одна карточка с числом непросмотренных результатов, пришедших за это время. Уже просмотренное
и результаты других чатов при выбранном важном чате повторно не отвлекают. Режим переживает
перезапуск; истёкший таймер обрабатывается при следующем запуске. Наведение и ручной пульт доступны.
